🔐 ISG SSH Heartbeat 명령어 생성기

ISG 대화형 CLI에서 enable 이후 diagnostics heartbeat view를 실행하고 결과를 heartbeat.txt로 저장합니다.

장비 주소와 ID를 입력하세요.

curl은 SSH 프로토콜을 지원하지 않습니다. 생성된 명령어는 PC의 터미널에서 실행해야 합니다. 일반 SSH 방식은 접속 시 비밀번호를 입력합니다. Plink의 -pw 옵션은 비밀번호가 명령 기록과 프로세스 목록에 노출될 수 있어 운영 환경에서 권장하지 않습니다. 최초 연결 시 서버 호스트 키를 검증하세요. ISG가 SSH 원격 명령 실행을 지원하지 않아 exec request failed 오류가 발생하면 SSH로 직접 로그인하여 diagnostics heartbeat view를 실행해야 합니다.
